## 设计研究

研究生阶段，我以第一作者发表了两篇论文。紫鹊界梯田研究中，我将遗产地资源、游客评价和数字文旅服务放在同一问题中梳理，讨论体验、内容和传播的设计切入点。云南非遗手工艺研究中，我用 CiteSpace 整理相关文献的关键词与研究方向，再讨论用户和社区参与视角。

- **场景与参与者**：我会明确体验者、服务方和文化内容提供者分别参与哪些环节，避免只设计单个屏幕。
- **资料与设计判断**：文献和评价资料能帮助我确定待验证的问题；具体交互是否有效，还需要观察实际使用并开展测试。
- **内容与体验**：在文化主题实践中，我检查角色、情节和视觉元素之间是否一致，再决定哪些生成结果进入最终方案。

我用这些研究方法组织问题和提出方案，也会继续在具体场景中检验作品的功能与视觉表达。
