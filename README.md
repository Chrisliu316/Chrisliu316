## 设计与研究

研究生阶段，我的两篇第一作者论文分别讨论农业遗产地数字文旅和云南非遗手工艺的数字化创新。它们让我把注意力从单一界面，延伸到体验发生的情境、参与者关系和内容表达。

- **从用户到社区**：在非遗研究中，结合以用户为中心的设计（UCD）与以社区为中心的设计（CCD），讨论体验者、传承者及其他参与者之间的关系。
- **从资料到问题**：通过文献可视化和游客评价分析梳理研究线索。对我而言，研究需要进一步回答具体体验中值得优先处理的问题。
- **从生成到表达**：在数字叙事实践中，关注生成内容与文化语境、角色设定、故事连续性的对应关系。

这些是我的研究关注；产品案例中的功能与视觉方案，仍需要结合具体场景分别检验。
